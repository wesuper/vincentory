# Blue Business Theme

蓝色商务风格 H5 汇报模板。

## 风格特征

- **主色调**：蓝色渐变（#1a5276 → #2980b9），专业、稳重
- **辅助色**：浅蓝（#d6eaf8）、高亮蓝（#3498db）
- **布局**：卡片式、三栏网格、时间轴、对比表格
- **动效**：柔和渐变过渡、悬浮上移、脉冲装饰

## 适用场景

- 年度/季度工作汇报
- 项目进展汇报
- 部门工作总结
- 商务演示

## 页面类型支持

- 封面页（渐变背景 + 装饰元素）
- 目录页（双栏布局，每栏最多 8 项）
- 内容页（三栏卡片 / 对比表格 / 时间轴 / 数据卡片）
- 图表页（ECharts / Mermaid）
- 图片展示页（含 Lightbox 预览）
- Q&A 页（居中动画）
- 附录页（表格 + 文字说明）

## 文件说明

| 文件 | 说明 |
|------|------|
| `style.css` | 完整 CSS 样式系统（~400 行） |
| `script.js` | SlideEngine + ImagePreview 交互（~140 行） |
| `skeleton.html` | HTML 骨架，含 CDN 引入和占位变量 |
| `page-templates.md` | 各页面类型的 HTML 结构规范 |
