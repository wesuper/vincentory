# H5 同频呈现与现场可控性

## 先做视觉剧本，不做页面装饰
内容源决定听众任务、关键判断、必要证据及边界；渲染者决定信息如何被看见。对每页从 title/takeaway/visible/visual_intent/notes 和 核心路线生成视觉意图：
- 第一眼定位：标题和主要证据关系；关键条件与来源标签同屏相邻，不能让焦点是导航或装饰。
- 讲述顺序：Cue 指向正确元素，Notes.Talk/Delivery 解释画面上没有直接展开的机制和取舍；Advance/Interaction 提供停顿和提问的时机。关键证据不可通过点击后才可见。
- 图形编码：数量→同口径图；比较→矩阵或真实新旧对照；流程→有根据的箭头；机制→状态/数据流图；无真实数量不绘制伪图，未知明确标记。颜色之外保留文字/形状标签。
- 跨页一致：同一个组件/状态/风险/单位在连续页名称、图例、位置、语义色一致；只有内容明确新增状态才改图，不用随机版式打断心智模型。复杂机制可拆层，关键前提和结论仍在主线。
- 重点/揭示：动画仅用于解释真实变化或顺序；默认静态完整可读，respect prefers-reduced-motion；不依赖动画时机、网络、hover 或声音才能得到证据。不能为动效隐藏风险或必要限制。
- 同频不等于自动感知听众。讲者通过问题、复述、观察、互动主动调整；不自动翻页、不虚构理解程度。

## 场景视觉路线（与原视觉路由配合）
| 场景 | 主要视觉 | 关键风险 |
|---|---|---|
| 领导方案 / 战略 | 决策提示、同口径备选矩阵、阶段门禁 | 把技术细节当价值、隐藏不做选项 |
| 架构评审 | 分层架构/状态/时序、失败路径、边界 | 图有连接却无真实关系、漏数据一致性 |
| 风险变更 | 风险/触发/影响/控制/停回条件矩阵、状态与窗口 | 红色代替证据、未验证回滚被画成可行 |
| 预期管理 | 原计划—当前—拟议对比、依赖及检查点 | 把预测画成承诺或虚构日期 |
| 成果/晋升 | 目标—证据—个人判断—结果—边界；对照与归因矩阵 | 活动清单、虚假分数、混淆团队/个人成果 |
| 深度分享 | 递进同构图、预测→机制→复现→反例、代码与输出 | 一次性展示复杂图、术语堆积、不可复现 |
| 团队宣导 | 角色任务/新旧流程/异常与支持/情境练习 | 只写口号、漏影响范围及生效状态 |
| 跨团队/复盘 | 泳道/接口/事实时间线/带限定的因果/责任表 | 把拟定分工画成已承诺或把推测当因果 |
| 客户方案 | 场景与能力/缺口映射、PoC 验收表 | 虚构案例、SLA 或安全承诺 |

`Visual Intent` 显式英文前缀优先（例如 `decision:`、`risk:`、`expectation:`、`attribution:`、`mechanism:`、`learning:`、`flow:`、`comparison:`）。自动路由是版式建议而非语义理解或全自动作图；基础渲染仅安全表达 Markdown 分组/表格/列表/明确流程。高级图需要基于源信息手工装配，逐项核对标签、关系、数据、口径，保留可读文字兜底；不能把未知数据补成漂亮图形。

## 演讲者路线
- 只有启用扩展且 `experience_quality.status=reviewed`、内容 ready、原 slide_quality reviewed 才可激活路线；基础稿不需要该路线也可正式验收。将 core_slide_ids 与 short_minutes 精确写入 `window.PRESENTATION_ROUTE`；未评审稿仅预览，不写路由。
- 正常左右键、下一页、宫格、计时均沿原页序。P 演讲者视图显示「核心页/可选深挖页」与核心备注预算；下一核心页不相邻才显示跳转按钮，点击跳到对应真实页。无下一核心页不显示按钮。不能自动跳过深挖页或改变正常导航。短路线不是另一份内容真源。
- Q&A：通过已有宫格或实际 slide_id 定位证据，必要时回主线；Cue/Fallback 提示如何恢复。所有场景关键约束在核心路线仍可见。
- 仅嵌入许可的 Speaker Notes 与最小路线 ID/预算。HTML 不保密；真实用户画像、未公开资料、全部内部 qa 不自动转入文件。

## 验收
在原 page_reviews 基础上增加 `synchrony`（可见焦点与口述一致）、`continuity`（跨页编码、术语、转场一致）、`core_route`（短路线完整，未启用扩展/无压缩需说明）及具体 basis。记录 `experience_quality`，浏览器实测短路线提示、按钮/普通下一页、末页无错误按钮、预览无激活、P 双屏同步、宫格返回、离线、两分辨率及屏幕无遮挡。未测不能填 pass；实测短路线跳转不代表真实听众接受。需现场调整内容则回传源文件。
