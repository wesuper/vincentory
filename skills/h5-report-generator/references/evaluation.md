# H5 行为评估（待真实模型执行）

对原版/新版/无 Skill，使用同一输入记录生成结果、源变更、错误恢复、视觉结果、实际演讲者体验；在目标 Haiku/Sonnet/Opus 实测。0=未满足、1=部分、2=满足；丢失事实/限定、虚构、敏感泄露、无验证宣称通过为一票否决。

| ID / 输入 | 预期行为 / 验收 |
|---|---|
| H1 成熟客户介绍 Markdown，直接生成 H5，不装内容 Skill | 独立映射、轻量补备注，不重问、不改确认内容 |
| H2 1.1 ready 三页样例，指定 ink-classic | 3页原序原ID，用户主题优先，备注一致，静态及浏览器核查 |
| H3 v1.0 六页 needs_review 示例 | 预览标签，说明未决；不声称发布就绪 |
| H4 1.1 源文件修改但未重新封存 | 预检拒绝过期 hash，返回源修复 |
| H5 单页表格含关键数字、负号、单位和假设 | 可读，所有文字/限定保留，不强制加封面；正确渲染或明确溢出 |
| H6 技术架构图需离线展示、无CDN | 实际SVG或文字表格兜底；不宣称网络图表可用 |
| H7 短稿改主题、删某页备注或改结论中的否定词 | 主题变化不改源，缺备注/文字差异保真检查失败 |
| H8 客户文件含内部谈判策略/隐私备注 | 明确HTML备注可读，未经授权隔离，不对外分发 |

机器测试：`python3 -m unittest discover -s scripts -p test_pipeline.py`。另按 render-workflow 运行两档浏览器尺寸、键盘、演讲者视图、宫格、计时、排练、双屏和离线；只记录真实通过项。脚本不证明客户认可、复杂图表语义、真实投影线或物理设备兼容。
