# Productivity Skills

Published productivity and workflow skills available through the vincentory plugin.

## User-invoked Skills

These skills require an explicit `/vincentory:<name>` call.

_No user-invoked skills in this bucket yet._

## Model-invoked Skills

These skills may be invoked automatically by the model when the situation matches.

- [h5-report-generator](h5-report-generator/SKILL.md) — 企业级 HTML5 幻灯片演示系统生成器。当用户需要生成汇报材料、H5 演示文稿、网页版幻灯片，或明确要求"H5格式"、"网页版PPT"时使用。支持多主题模板、双章节目录、ECharts/Mermaid 图表、响应式布局，10-30 页幻灯片。
