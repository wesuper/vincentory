# 展示侧效果设计
读取内容源中已授权的 Cue/Interaction/Advance/Fallback；若存在内部效果计划，仅用于核对关键页是否支撑目标，不将计划、观察、评分、听众画像或来源记录嵌入 HTML。
按关键节点进行「可见证据 → 口播解释 → 观察信号 → 恢复」审查。决策页突出可选择项与条件；机制页用一致坐标系支持预测和反例；宣导页用真实情境检验执行路径。没有用户授权不新增互动题或改写内容，回传 slide_id 和建议。
逐页审查额外记录 focus（第一眼焦点）、cue_match（口播与证据对应）、recovery（误解时是否有可读证据/恢复入口）、basis（具体依据）；不适用说明理由。只在有真实认知任务时加入渐进揭示，默认完整静态可读。不要加入自动情绪识别、听众追踪、自动打分或自动翻页。
会后若用户提供反馈，区分视觉问题、内容问题、会议外部约束；视觉修复保留源 hash，语义修订回内容侧。真实效果独立于 presentation_ready。原有 P、核心路线、双屏、离线和保真门禁不变。
