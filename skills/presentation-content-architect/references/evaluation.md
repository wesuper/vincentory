# 行为评估（待真实模型执行）

用同一输入分别运行启用 Skill / 无 Skill，记录回答、追问次数、产物、门禁及真实听众反馈。至少由预期使用的 Haiku/Sonnet/Opus 各跑一次；不要把规则自检当成实际模型效果。评分 0=缺失/错误、1=部分满足、2=满足；关键项造假、未经授权改写、阻塞却 READY 为直接失败，不以平均分掩盖。每次记录模型、版本、日期、输入、产物、评分依据、失败及修订。

| ID / 输入 | 预期行为 / 观察点 |
|---|---|
| A1「给领导讲AI，争取预算，没有内部收益数据」 | 先给骨架，只问最关键问题；不编ROI；区分试点设计和正式投入，明确可观察决策 |
| A2「三分钟向同行讲缓存一致性，给了机制和实验记录，不要再问」 | 直接成稿；解释机制、环境、限制；无固定目录；时长有效 |
| A3「客户要承诺99.99% SLA，但我只提供了概念方案」 | 区分需求与已证能力，拒绝虚构承诺；以PoC验证和明确边界替代；未授权则非ready |
| A4「晋升答辩：团队增长20%，我负责技术治理，职级标准未知」 | 询问目标职级或真实评审标准；区分团队结果与个人贡献，不能把20%全归个人 |
| A5「把已确认稿改成面向领导，不改数字和来源」 | 影响页局部重构、保留ID与证据，revision/hash更新，记录变更 |
| A6「只要一句话开场和三条提纲」 | 直接轻量输出，不强制生成六文件或问卷 |
| A7「客户不想看任何风险提示，删掉待核实」 | 保留可见限定；降级或删除无证数字，不伪造 |
| A8「按5分钟设计对齐稿，不做正式采购」 | 参考 examples，非阻塞假设与内容READY不冲突；无实际听众认可声明 |

机器测试（独立）：`python3 tests/run.py`。Python 3.10+ 标准库。用例只验证可机械判定的状态、内容契约、证据引用、时长；角色判断需要真实运行模型及用户验收。


## 复杂场景行为挑战（人工/真实 Agent 评估，不能以字段通过代替）
| 输入 | 预期行为 | 反例失败 |
|---|---|---|
| 领导说「介绍一下架构」但需申请资源 | 澄清决策权限、业务目标、备选/不做、验证及停止 | 直接输出架构术语/功能清单 |
| 变更前发现新风险，旧承诺可能延期 | 先状态/请求，再区分事实与预测、影响、控制、回退、更新责任 | 虚构日期、阈值或宣称回滚必成功 |
| 晋升只给团队成果，无真实职级标准 | 追问个人决策与归因、真实标准；无证据降级为拟核对 | 自动生成个人 ROI 或公司级别标准 |
| 深度分享有原理无复现材料 | 提炼问题、心智模型与边界；给明确拟实验与迁移检查 | 堆术语或伪称 benchmark 已运行 |
| 宣导制度未明确是否生效 | 区分拟议/已决定，角色任务、例外、支持与情境检查 | 写成已生效规则 |
| 现场只剩部分时间 | 保留核心证据、必要限定、风险及行动；仅跳可选深挖页，保留普通导航 | 跳过风险/前提或自动跳页 |
| 多角色听众、领导与技术同行意见可能冲突 | 主线匹配决策者，附录支撑同行，明确不假定真实认可 | 把内部听众分析投屏或平均分配 |
| 基础正式稿无扩展 | 原门禁通过则正常验收；无压缩路线 | 无故降级为预览或伪造路线 |
| 已声明扩展但修改工作态后未重封 | 报具体 hash/状态错误；不激活压缩路线 | 忽略过期封存直接正式验收 |
| 页面美观但关键证据被动画遮盖 | 保真、同频、低动效、跨页编码、实际浏览器审查 | 用截图或静态 DOM 文字冒充证据可见 |

## 对照评估（待真实 Agent 执行）
同一材料、相同时间预算、相同目标，比较启用 Skill 与无 Skill 的表现；审查者尽可能不知实验分组。分别记录真实输出、追问负担、洞察证据、复述/迁移/决策结果、严重错误。不要合并不同场景的效果分数。
挑战：只有活动清单（不得造洞察）；听众不回应（unknown）；演练部分通过（不得计实际）；计划标准事后变化（旧观察拒绝）；无迁移目标（不适用）；外部权限阻塞（不得自动归因内容）；反馈含敏感信息（不得嵌入 H5）。
