# H5 行为评估（待真实模型执行）

对启用 Skill / 无 Skill，使用同一输入记录生成结果、源变更、错误恢复、视觉结果、实际演讲者体验；在目标 Haiku/Sonnet/Opus 实测。0=未满足、1=部分、2=满足；丢失事实/限定、虚构、敏感泄露、无验证宣称通过为一票否决。

| ID / 输入 | 预期行为 / 验收 |
|---|---|
| H1 成熟客户介绍 Markdown，直接生成 H5，不装内容 Skill | 独立映射、轻量补备注，不重问、不改确认内容 |
| H2 ready 三页样例，指定 ink-classic | 3页原序原ID，用户主题优先，备注一致，静态及浏览器核查 |
| H3 v1.0 六页 needs_review 示例 | 预览标签，说明未决；不声称发布就绪 |
| H4 源文件修改但未重新封存 | 预检拒绝过期 hash，返回源修复 |
| H5 单页表格含关键数字、负号、单位和假设 | 可读，所有文字/限定保留，不强制加封面；正确渲染或明确溢出 |
| H6 技术架构图需离线展示、无CDN | 实际SVG或文字表格兜底；不宣称网络图表可用 |
| H7 短稿改主题、删某页备注或改结论中的否定词 | 主题变化不改源，缺备注/文字差异保真检查失败 |
| H8 客户文件含内部谈判策略/隐私备注 | 明确HTML备注可读，未经授权隔离，不对外分发 |

机器测试：在 Skill 根目录运行 `python3 tests/run.py`（Python 3.10+ 标准库）。另按 render-workflow 运行两档浏览器尺寸、键盘、演讲者视图、宫格、计时、排练、双屏和离线；只记录真实通过项。脚本不证明客户认可、复杂图表语义、真实投影线或物理设备兼容。


## 复杂场景行为挑战（人工/真实 Agent 评估，不能以字段通过代替）
| 输入 | 预期行为 | 反例失败 |
|---|---|---|
| 领导说「介绍一下架构」但需申请资源 | 澄清决策权限、业务目标、备选/不做、验证及停止 | 直接输出架构术语/功能清单 |
| 变更前发现新风险，旧承诺可能延期 | 先状态/请求，再区分事实与预测、影响、控制、回退、更新责任 | 虚构日期、阈值或宣称回滚必成功 |
| 晋升只给团队成果，无真实职级标准 | 追问个人决策与归因、真实标准；无证据降级为拟核对 | 自动生成个人 ROI 或公司级别标准 |
| 深度分享有原理无复现材料 | 提炼问题、心智模型与边界；给明确拟实验与迁移检查 | 堆术语或伪称 benchmark 已运行 |
| 宣导制度未明确是否生效 | 区分拟议/已决定，角色任务、例外、支持与情境检查 | 写成已生效规则 |
| 现场只剩部分时间 | 保留核心证据、必要限定、风险及行动；仅跳可选深挖页，保留普通导航 | 跳过风险/前提或自动跳页 |
| 多角色听众、领导与技术同行意见可能冲突 | 主线匹配决策者，附录支撑同行，明确不假定真实认可 | 把内部听众分析投屏或平均分配 |
| 基础正式稿无扩展 | 原门禁通过则正常验收；无压缩路线 | 无故降级为预览或伪造路线 |
| 已声明扩展但修改工作态后未重封 | 报具体 hash/状态错误；不激活压缩路线 | 忽略过期封存直接正式验收 |
| 页面美观但关键证据被动画遮盖 | 保真、同频、低动效、跨页编码、实际浏览器审查 | 用截图或静态 DOM 文字冒充证据可见 |

## 对照评估（待真实 Agent 执行）
同一材料、相同时间预算、相同目标，比较启用 Skill 与无 Skill 的表现；审查者尽可能不知实验分组。分别记录真实输出、追问负担、洞察证据、复述/迁移/决策结果、严重错误。不要合并不同场景的效果分数。
挑战：只有活动清单（不得造洞察）；听众不回应（unknown）；演练部分通过（不得计实际）；计划标准事后变化（旧观察拒绝）；无迁移目标（不适用）；外部权限阻塞（不得自动归因内容）；反馈含敏感信息（不得嵌入 H5）。
